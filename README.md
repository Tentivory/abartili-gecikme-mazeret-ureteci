# Abartılı Gecikme Mazeret Üreteci

## Bu Nedir?

Bu, insanlık tarihinin en büyük teknolojik atılımıdır. Artık işe, okula, randevuya, hatta kendi evinize bile geç kalmanız için bilimsel, felsefi ve tamamen saçma mazeretler üretebiliyorsunuz.

Diğer gecikme mazeret uygulamalarının aksine, bu program **gerçekten çalışır**. Yani çalışır. Mazeret üretir. Sonra durur. Çünkü sonsuz döngüye girerse evren çöker.

## Özellikler

- %100 çalışan Python kodu
- Rastgele seçilen abartılı mazeretler
- Hiçbir şey yapmazken bir şey yapıyormuş gibi görünür
- Patronunuz inanmasa bile siz inanırsınız
- Kedi yutma, zaman genişlemesi ve takvim hataları dahil

## Kullanım

```bash
python mazeret.py
```

Sonra çıkan mazereti kopyala, patrona gönder, işinden ol.

## Uyarı

Bu yazılımı kullanmak, gecikmenizi meşrulaştırmaz. Sadece daha eğlenceli hale getirir. Eğer işten atılırsanız, bu repo sorumluluk kabul etmez. Sorumluluk, mazeretin kendisindedir.
